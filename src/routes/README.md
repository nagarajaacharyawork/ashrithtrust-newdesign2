# Routes

TanStack Router uses **file-based routing**. Every `.tsx` file in this directory defines a route.

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `users/$id.tsx` | `/users/:id` |
| `__root.tsx` | app shell — wraps every page; preserve `<Outlet />` |

`routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin. Don't edit it by hand.
